# 👋 Hey, I'm Kevin

**Principal Engineer at ELEV8TEK.** I make sure AI-built software actually works: testing, code review and post-launch care.

I started as an intern in 2022, became a tech lead in under two years, and now own the testing standards for a team where AI agents write a growing share of the code. Outside work I love live music, hiking, animals and rainy days.

## What I do

- **Review code, including code written by AI agents**, against a written quality bar before it ships
- **Build the safety net**: unit tests, end-to-end tests, load tests and CI pipelines that catch problems before users do
- **Look after apps after launch**: triage production issues, add staging environments and make releases safer
- **Lead and mentor**: I've reviewed 500+ pull requests from 50+ developers, many of them interns in their first role
